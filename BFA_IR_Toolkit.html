File Size Thresholds & Suspicious File Types
Quantitative trigger values for Symantec EDLP and Squid 6.14 proxy enforcement. Each channel uses a three-band model: Normal (no action), Alert (Helpdesk notified), Block (transfer stopped and incident raised).
Transfer Thresholds by Channel
Channel Normal — No Action Alert — Helpdesk Notified Block — Transfer Stopped BFA-Specific Note
Outbound EmailOffice 365 < 10 MB 10 – 25 MB > 25 MB Flag .csv, .xlsx and .sql at any size — even small exports may contain all 10,000 client records. Monitor for external forwarding rules.
HTTP/S Web UploadSquid 6.14 Proxy < 5 MB 5 – 20 MB > 50 MB Block all uploads to Dropbox, WeTransfer, and personal Google Drive at any file size. No legitimate business reason exists for these destinations.
Client Web UploadsIIS 10 / Windows Server 2022 < 2 MB 2 – 10 MB > 10 MB BFA's client portal is a budgeting tool — large uploads are operationally abnormal. Above 10 MB may indicate a web shell upload attempt to the IIS web root.
SQL Exports & BackupsSQL Server / Windows Server 2016 < 50 MB 50 – 200 MB > 500 MB Any .bak, .mdf or .sql file accessed outside business hours (8 PM–6 AM AEST) triggers an automatic alert regardless of file size. This server holds all client financial data.
Local Archive CreationEndpoint Device < 25 MB 25 – 100 MB > 100 MB + upload Archive creation (.zip, .7z, .rar) followed immediately by an outbound transfer is a data staging pattern used in insider threat and ransomware double-extortion operations.
USB / Removable MediaEndpoint Device Approved use only Unclassified > 5 MB Any client / financial data Account managers have no legitimate business need for USB data transfers. Block all client PII and financial data to removable media with no exceptions.
OneDrive / SharePoint SyncOffice 365 Normal sync activity > 500 files or 100 MB in 5 min > 1 GB or after-hours bulk Departing account managers are the highest-risk profile. A resignation event combined with elevated bulk download activity triggers an immediate insider threat review.
